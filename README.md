# AI Slide Generator

Describe a presentation topic, get a full slide deck generated by Gemini, preview it in-browser
with reveal.js, tweak the text, and download it as a real `.pptx` file. Runs entirely on Netlify's
free tier — no database, no paid services.

## How it works

- `index.html` / `style.css` / `app.js` — the whole frontend, plain HTML/CSS/vanilla JS (no build step).
- `netlify/functions/generate-slides.js` — the only server-side code. It holds the secret Gemini API
  key and calls Gemini on the browser's behalf, so the key never reaches the client.
- Slide preview uses [reveal.js](https://revealjs.com/) (via CDN). Export uses
  [PptxGenJS](https://gitbrent.github.io/PptxGenJS/) (via CDN) — the `.pptx` file is built entirely
  in the browser from the same slide JSON you see in the editor.

## 1. Get a free Gemini API key

1. Go to [Google AI Studio](https://aistudio.google.com/apikey).
2. Sign in with a Google account and click **Create API key**.
3. Copy the key — you'll need it in step 3 below. Keep it secret; do not commit it anywhere.

The function defaults to the `gemini-2.5-flash` model, which is free-tier eligible. If Google
renames or retires it, update `MODEL_NAME` in `netlify/functions/generate-slides.js` — check
[ai.google.dev/gemini-api/docs/pricing](https://ai.google.dev/gemini-api/docs/pricing) for the
current free-tier model list.

## 2. Install dependencies (for local testing)

You'll need [Node.js](https://nodejs.org/) and the [Netlify CLI](https://docs.netlify.com/cli/get-started/):

```bash
npm install
npm install -g netlify-cli
```

## 3. Set your API key locally

Create a `.env` file in the project root (already gitignored, never committed):

```
GEMINI_API_KEY=your-key-here
```

## 4. Run it locally

```bash
netlify dev
```

This serves `index.html` and runs `generate-slides.js` as a local function, so the whole flow
(including the AI call) works exactly like production. Open the URL it prints (usually
`http://localhost:8888`).

## 5. Deploy to Netlify

1. Push this project to a Git repo (GitHub/GitLab/Bitbucket).
2. In the [Netlify dashboard](https://app.netlify.com/), click **Add new site → Import an existing
   project**, and connect the repo. Netlify will read `netlify.toml` automatically — no build
   command is needed.
3. Go to **Site settings → Environment variables** and add:
   - `GEMINI_API_KEY` = your key from step 1
4. Deploy. Netlify builds the site and the function together.
5. Open the deployed URL, generate a real deck, edit a slide, and download the `.pptx` to confirm
   it opens correctly in PowerPoint/Google Slides/Keynote.

## Limits & abuse protection

- Topic capped at 500 characters, audience at 200, slide count clamped to 3–25.
- A simple per-IP throttle in the function rejects requests faster than one per ~8 seconds with a
  friendly 429 message, to protect the shared free Gemini quota.
- The API key lives only in Netlify's environment — it's never sent to the browser or bundled
  into any client-side file.

## Notes

- No accounts, no database — decks live only in the browser tab until you download them.
- Netlify Functions free tier (125k invocations/month, 100 hrs runtime/month) comfortably covers
  personal or small classroom use.
